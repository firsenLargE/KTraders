Backup Information
  • Automated Backups: The system automatically creates backups every day at 2:00 AM
  • Retention: Backups older than 30 days are automatically deleted to save space
  • Manual Backups: You can create additional backups anytime using the "Create Backup Now" button
  • Storage: All backups are stored in the ./backups directory
  • Restore: To restore a backup, download the SQL file and use PostgreSQL's psql command
